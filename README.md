# Homebrew Tap

Custom Homebrew tap for nguyenphutrong's applications.

## Installation

```bash
brew tap nguyenphutrong/tap
```

## Available Packages

### Quotio (Cask)

Command center for AI coding assistants on macOS.

- **GitHub**: https://github.com/nguyenphutrong/quotio

```bash
brew install --cask quotio
```

### cpa-plusplus (Formula)

OpenAI/Gemini/Claude/Codex compatible API proxy with OAuth and round-robin load balancing.

- **GitHub**: https://github.com/nguyenphutrong/cpa-plusplus

```bash
brew install cpa-plusplus
```

### Agentlens (Formula)

Prepare codebases for AI agents with structured documentation.

- **GitHub**: https://github.com/nguyenphutrong/agentlens

```bash
brew install agentlens
```

## Uninstallation

```bash
# Remove quotio
brew uninstall --cask quotio

# Remove agentlens
brew uninstall agentlens

# Remove tap
brew untap nguyenphutrong/tap
```
